# gbmake & gbplot

gbmake and gbplot: Stata programs for revealing volatility dynamics in ARCH-GARCH models. Website: https://andyphilips.github.io/gbmake-gbplot/

## Install

```stata
net install gbmake, from("https://andyphilips.github.io/gbmake-gbplot/") replace
```

See website above for details.
